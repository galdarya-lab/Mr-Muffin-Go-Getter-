# Willow Manor — The Mystery of Mr Muffin

## Запуск

1. Сохраните всю папку `Willow_Manor_Presentation` на компьютере. Не выносите `index.html` из папки.
2. Дважды нажмите `index.html`. Подойдёт актуальный Chrome, Edge или Firefox. Сервер, установка, регистрация и интернет не нужны.
3. Откройте «Учителю», выберите уровень группы и проверьте аудио до урока.
4. Нажмите Start. На карте выберите комнату или First room.

Кухни A/B распечатайте и раздайте разным командам. На проектор выводится только нейтральная кухня. Чтение и ответы на экран автоматически не выводятся.

## Проведение урока

- Reveal the cat показывает кота и реплику. Повторное нажатие ничего не сбрасывает.
- Next room доступна всегда. Можно пропускать задания и возвращаться назад.
- Учителю → Показать кота позволяет завершить и игру отличий досрочно. Это осознанное управление учителя, не автоматическая проверка знаний.
- Map открывает все этапы. «The Final Room» до входа не называет зимний сад.
- Панель учителя содержит подсказки и ограничения материалов. Не держите её открытой во время самостоятельных ответов детей.
- Основная группа использует Present Continuous и some / any. Начальная группа описывает комнаты через there is / there are. В этом режиме Next room из кухни пропускает Usually / Today. Любой этап всё равно доступен на карте.
- В финальной комнате сначала нажмите Reveal the cat, затем Mrs Willow. Последняя кнопка раскрывает её благодарность. При добавленном портрете покажется и он.
- Прогресс, открытые коты, отметки игры, уровень группы, ссылка на видео и настройка анимаций сохраняются в localStorage этого браузера. После обновления предлагается продолжить или открыть начало, сохранив открытия. Для полного сброса используйте «Начать сначала» и подтвердите.
- При запрете localStorage появится уведомление в панели. Приложение продолжит работать в памяти. Перемещение папки, другой браузер и приватный режим могут изменить доступность сохранений.
- Клавиатура: Tab / Shift+Tab для кнопок, Enter / Space для активации; ← / → для переходов, R для раскрытия, M для карты, T для панели, Esc для закрытия панели или диалога. Горячие клавиши не вмешиваются в ввод текста и управление медиаплеером. В игре клавиатурой используйте панель и «Завершить этап» вместо точек.
- Full screen включает полноэкранный режим, если браузер разрешает. Можно воспользоваться F11.
- Анимации отключаются в панели и автоматически учитывают системную настройку уменьшения движения.

## Аудио и видео

Аудио `assets/audio/listening.mp3` запускается только вручную: Play, Pause, Replay и стандартный плеер с перемоткой. При уходе из комнаты запись ставится на паузу. Текст записи не расшифрован и не проверен по листам. Прослушайте до урока. При отсутствующем файле или отсутствии звука можно прочитать собственный текст или пропустить этап.

Финальное видео необязательно:

1. «Учителю» → «Видео про Mr Muffin» → выберите локальный файл.
2. В финале появится Watch Mr Muffin’s Day. Видео открывается с обычными кнопками управления, без автозапуска.
3. Файл никуда не загружается. После перезагрузки браузер требует выбрать его повторно.
4. Для постоянного подключения положите ролик в `assets/video/` и укажите относительный путь в поле `video` файла `config.js`.
5. Можно вместо файла сохранить ссылку http/https и вручную открыть её кнопкой в панели учителя. Внешняя ссылка потребует интернет. Автоматических переходов нет.

## Поиск отличий: честный ручной режим

Оригиналы `picture_a.jpeg` и `picture_b.jpeg` сохранены без изменений. Обе картинки отображаются целиком, рядом на широком экране и друг под другом на узком.

Проверка исходных картинок подтверждает девять изменений из старого ключа: поза полосатого кота в кресле; еда/молоко у рыжего кота; поза белого кота на подоконнике; цвет мяча; коробка/корзина; птица/бабочка на картине; цвет штор; количество книг; цвет подушки. Цветок в вазе **есть на обеих картинках**. Поэтому десятое отличие старого ключа не подтверждается. Мелкие непреднамеренные изменения не объявлены правильными ответами. Имена котов в предложениях заменены описанием внешности или положения, чтобы не приписывать им неподтверждённые личности по фотографии.

Вместо фиктивной десятой зоны используется обсуждение с ручными отметками преподавателя:

1. Нажмите наблюдаемое отличие на Picture A, затем соответствующее место на Picture B.
2. В диалоге выберите подходящее предложение или введите своё английское предложение. Нажмите «Засчитать» только после проверки.
3. На обеих картинках останутся пронумерованные кружки. Счёт увеличится один раз. Та же область в пределах 5% от точки и повтор выбранного наблюдения блокируются. Ручной режим всё равно требует проверки учителем.
4. Предложения появляются после подтверждения. Hint даёт общий ориентир. Reset очищает отметки только после подтверждения.
5. Не ищите вымышленное десятое отличие. После девяти подтверждённых наблюдений завершите этап через «Учителю» → «Завершить этап» или «Показать кота». Появится Sherlock. Маффин на этом этапе не показывается.
6. Если учитель независимо подтвердил другое отличие, можно использовать «Наблюдение преподавателя» и ввести своё предложение. После десяти ручных подтверждений доступно обычное Reveal the cat. Программа не утверждает, что десять пунктов исходного ключа верны.

При отсутствии картинок остаются навигация и завершение учителем. Автоматической проверки правильности точек нет.

## Структура

`index.html` — оболочка и панель; `style.css` — адаптивное оформление; `config.js` — пути ко всем материалам; `app.js` — сценарий и сохранение; `assets/` — оригинальные ассеты. Зависимостей и сборки нет. Для переноса или отправки используйте всю папку или ZIP.

## Проверка и ограничения

Проверки реализации и интерактивной логики описаны в `VALIDATION.md`. Полная визуальная проверка в реальном браузере в среде создания недоступна: подключённого браузера нет. Перед уроком откройте `index.html` на компьютере с проектором, проверьте размер шрифта и громкость, пройдите карту и финал. При необходимости используйте масштаб браузера.

Приложение не публиковалось, не использует аналитику, CDN, удалённые шрифты или сетевые запросы. Интернет нужен только если преподаватель сам открывает необязательную внешнюю ссылку на видео.
